# Interface icons

Six local SVGs from Lucide, downloaded from the official repository:
https://github.com/lucide-icons/lucide/tree/main/icons

Sources: plus.svg, x.svg, printer.svg, download.svg, check.svg and trash.svg.
The last is stored as trash-2.svg locally. No geometry was modified.
The ISC and inherited Feather MIT notices are preserved in LICENSE.

The application uses these SVGs as CSS masks in currentColor. No Lucide
runtime, CDN or package installation is required by the application.
